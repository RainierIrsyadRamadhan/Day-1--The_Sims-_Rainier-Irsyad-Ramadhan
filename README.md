# Repository

Repository merupakan tempat penyimpanan digital yang digunakan untuk menaruh, mengelola, serta mengatur berbagai berkas, data, atau kode. Fungsi repository berfokus pada efisiensi pengelolaan, keamanan data, dan kemudahan akses dalam mencari suatu kode

# Kegiatan Workshop Day-1

Secara keseluruhan workshop day-1 menjelaskan terkait cara merancang instruksi pada AI (prompting) dengan lebih profesional agar menghasilkan jawaban yang tepat, relevan, dan layak dengan tidak memberi peringkat yang singkat namun memberikan konteks lebih lanjut dalam suatu prompt. Lalu dilanjutkan dengan penjelasan terkait github yang merupakan tempat penyimpanan dan kolaborasi untuk repositori git. Git sendiri merupakan version control system yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file.

Git memiliki beberapa workflow, seperti working directory/tree yang merupakan salinan dari suatu versi proyek yang sedang dikerjakan, git directory yang merupakan tempat menyimpan metadata dan objek database dari sebuah proyek, dab staging area yang berfungsi untuk menyimpan informasi terkait perubahan apa saja yang akan dimasukkan ke dalam commit berikutnya.

Git memiliki command penting tersendiri, seperti:
1. git init --- untuk memulai repo baru
2. git add. --- untuk memindahkan file ke staging area
3. git commit -m 'message; --- untuk menyimpan file ke repository
4. git remote add <name> <url> --- untuk menambahkan file atau perubahan yang tidak terlacak
5. git push origin main --- untuk memindahkan cabang yang sekarang ke cabang yang lain
6. git pull origin main --- untuk mengambil perubahan dan menyatukannya ke cabang yang sekarang

---------------------------------------------------------------

Dari workshop day-1, dapat diambil poin-poin dan pengetahuan baru yang dapat dipelajari, seperti:
1. Bagaimana cara untuk prompting yang baik dan benar agar hasil dari prompt tersebut tidak kurang
2. Definisi, workflow, dan command penting yang terdapat pada git
3. Cara menginstall git itu tersendiri

Pendapat saya terkait workshop day-1 ini adalah, kegiatan ini secara keseluruhan merupakan kegiatan yang menarik, dan banyak juga ilmu yang bisa didapatkan ketika menghadiri acara ini. Challenge membuat task planner menggunakan AI dan menguploadnya ke github melalui git juga memberikan experience yang menantang.
